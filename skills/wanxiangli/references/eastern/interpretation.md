# 易理、历法和五行

`hexagrams.json` 的 64 卦下上卦与初爻至上爻六位编码据 `zhouyi` 卦表整理；卦名可靠，`theme`、`tone` 是本项目的简化解释，并非原典吉凶原话。

起卦法：从本日 seed 的独立 `hexagram` 通道等概率抽取 64 卦。这里是本项目的“日签”，不是蓍草或铜钱六爻起卦；没有动爻、变卦，也不应伪称有之。解释时给出卦名、下卦、上卦、主题，再说今日行动。

`lunar-python` 提供农历、年/月/日干支、节气、纳音、黄历原文宜忌、彭祖百忌与黄道神煞。原文宜忌保留在 JSON；`MODERN` / `DONTS` 只将少数明确可迁移的条目转为现代语言，其余不硬译。五行若展示，注明干支与纳音的口径，不凭五行判考试成败。

历法按指定时区的民用日期运行；本地正午用来固定天文取样，节气所在日还需注意不同地区的时间边界。传统黄历宜忌是民俗规则，不是经验因果事实。
